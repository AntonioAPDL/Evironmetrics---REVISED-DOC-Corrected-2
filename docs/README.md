# Documentation

This directory contains submission-facing documentation for the revised article
repository. It records provenance, model-output wiring, and reproducibility
contracts for the manuscript files that are tracked in this repo.

Recommended reading order:

1. `article_repository_structure.md`
2. `figure_table_provenance.md`
3. `exal_m_t1_artifact_run_map.md`
4. `forecast_design_contract.md`
5. `latest_forecast_issue_contract.md`
6. `runtime_benchmark_contract.md`
7. `software_availability_contract.md`

Local planning notes, reviewer-workbench trackers, poster drafts, and audit
galleries are intentionally kept out of the tracked submission repo. When
needed, they are preserved locally under ignored `local_notes/` or regenerated
from the workflow repository.
